# Frontier Research

Prefer current primary sources: official docs/specs, upstream repositories, release notes, standards and first-party evidence. Record dates/versions because agent and plugin contracts change quickly.

Separate source facts from synthesis. Actively search for evidence that falsifies the preferred architecture or performance story.

When researching Aftergraph itself, refresh live repository heads and compare them with the packaged knowledge snapshot. Keep private/internal evidence and public upstream evidence provenance distinct.

Research can propose architecture, model/provider choices and capability maturity, but cannot grant execution authority or promote an integration to verified without the required operational evidence.

Return findings, contradictions, source/version boundaries, implications and specific claims that remain unverified.
